# AfelixPromo 1.0.0 — primeira versão oficial

O AfelixPromo chegou! Encontre ofertas de lojas parceiras da Bruna Felix em um só lugar.

## Nesta versão

- Pesquise entre 18 lojas e consulte suas 18 ofertas iniciais.
- Veja descontos e cupons disponíveis para cada oferta.
- Copie cupons com facilidade ou abra diretamente a loja.
- Saiba quando um link pode ser afiliado.
- Use o app em celulares, tablets e dispositivos dobráveis, com uma interface que se adapta ao espaço disponível.

O catálogo vem incluído no aplicativo e pode ser consultado sem conexão. É necessário acesso à internet para carregar imagens das lojas e abrir destinos externos.
